10 / AYUDA

Soporte y solución de problemas

La laptop no enciende

Comprueba el cargador y la conexión eléctrica. Si el problema continúa, solicita asistencia técnica.

No hay Internet

Comprueba que el Wi-Fi esté activado y verifica que la red seleccionada tenga conexión.

El equipo está lento

Cierra aplicaciones que no utilices, revisa el espacio disponible y reinicia el equipo.

No hay sonido

Comprueba el volumen, el dispositivo de salida y que el sistema no esté en silencio.

DIAGNÓSTICO

Catálogo de Errores Comunes

Identificación de fallos mediante luces LED y alertas del sistema.

LED parpadea Ámbar/Blanco

Causa: Falla en la batería o memoria RAM.
Solución: Verificar cargador o contactar soporte técnico de Dell.

Pantalla Azul (BSOD)

Causa: Error crítico de software o controlador.
Solución: Reiniciar el equipo. Si persiste, restaurar el sistema operativo.

Error "No Boot Device Found"

Causa: El disco duro/eMMC no es detectado.
Solución: Ingresar a la BIOS (F2) y revisar la configuración de arranque.

Calentamiento Excesivo

Causa: Obstrucción en la ventilación o uso rudo.
Solución: Usar en superficies planas y duras; no sobre camas o sofás.

DICCIONARIO TÉCNICO

Glosario de Términos

Conceptos clave para entender mejor tu computadora.

eMMC / SSD

Tipos de almacenamiento interno donde se guarda el sistema operativo, los programas y tus archivos personales de forma permanente.

Memoria RAM

Memoria de trabajo a corto plazo. Entre más RAM, más programas y pestañas del navegador puedes tener abiertos al mismo tiempo sin que el equipo se ponga lento.

Touchpad

Panel táctil ubicado debajo del teclado que funciona como sustituto del ratón (mouse) para mover el puntero en la pantalla.

BIOS / UEFI

Sistema básico que arranca antes que Windows. Controla el hardware desde el nivel más bajo y permite configuraciones avanzadas del equipo.
